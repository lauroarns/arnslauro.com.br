# arnslauro.com.br

Site de Lauro Arns Meirelles de Miranda, psicólogo (CRP 08/49039).

- `index.html`: página principal
- `logoterapia.html`: crise existencial, vazio e esgotamento (o título muda com `?tema=esgotamento` ou `?tema=crise`)
- `luto.html`, `relacionamentos.html`, `novo-diagnostico.html`: páginas temáticas para os anúncios
- `assets/`: estilos, script de medição (GA4 + Google Ads) e mídias
